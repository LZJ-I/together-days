开启加密评论

继续使用当前 GitHub 仓库和 Vercel 项目，不需要新增数据库。现有的管理密码、会话密钥和 GitHub 令牌保持原值。

1. 核对 GitHub 令牌

在 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens 中，找到 Vercel 的 GITHUB_TOKEN 所对应的令牌。Repository access 仅选择网站仓库，Repository permissions 中的 Contents 设为 Read and write。如果原来已能保存记录，一般无需再增加权限。

2. 确认评论数据分支

评论单独保存在 comments-data 分支。该分支的 vercel.json 禁止自动部署；请勿合并进 main，也不要在 Vercel 中手动部署该分支。

3. 添加评论密钥

在 Vercel 项目的 Settings → Environment Variables 中，为 Production 添加下面两项：

COMMENTS_BRANCH
comments-data
COMMENT_ENCRYPTION_KEY
使用下方生成的独立随机密钥。

生成的密钥不会发送到服务器，刷新本页后会清空。

请先备份密钥。存入评论后，保留同一个密钥；更换或丢失它会使旧评论无法解密，也会影响原来的留言限制。它与登录会话密钥用途不同。

也可以在本地终端生成：

node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"

4. 部署后验证

保存环境变量后重新部署 Production。在后台为对应情侣开启评论区，提交一条测试留言；刷新后应显示已留言。在「评论管理」中删除后，主页不再显示，留言限制仍保留。需要重新测试时，可单独点击「允许再次留言」。
