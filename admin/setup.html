让后台开始工作

页面由静态文件展示，登录与保存由同一 Vercel 项目的接口处理。记录保存到 GitHub 仓库，提交后沿用该仓库的自动部署。

1. 准备仓库令牌

在 GitHub 创建一个 fine-grained personal access token，仅选择这个网站的仓库，将 Contents 权限设为 Read and write。目标分支需要允许该账号直接提交。

前往 GitHub 创建令牌 ↗

2. 添加 Vercel 环境变量

进入项目的 Settings → Environment Variables，在 Production 中添加以下配置：

ADMIN_PASSWORD
自行设置的管理密码，至少 12 个字符。
ADMIN_SESSION_SECRET
至少 32 个字符的随机会话密钥。可以在本地运行下方命令生成。
GITHUB_TOKEN
刚创建的 GitHub 仓库令牌。
GITHUB_REPOSITORY
仓库的「所有者/名称」，例如 your-name/your-repository。
GITHUB_BRANCH
需要保存和部署的分支，默认 main；使用其他分支时填写。

密码、密钥和令牌只填写在环境变量中。

3. 重新部署并登录

代码部署到 Vercel 后，重新部署以使环境变量生效，再打开 /admin/ 输入管理密码。默认仅 Alex/Sam 开启异地与见面记录，可在后台为其他情侣单独开启。

保存后会生成一笔 GitHub 提交；主页在对应的 Vercel 部署完成后更新。
